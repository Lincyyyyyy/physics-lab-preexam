# physics-lab-preexam

Tampermonkey 用户脚本，用于在科大奥锐大学物理实验预习系统中自动填写预习题答案并提交。

## 功能

- 从当前试卷的 `NewContentXml` 中读取标准答案 `StdAnswer`。
- 自动填写单选题、多选题、判断题和填空题。
- 试卷加载后自动提交，也可点击页面右下角“一键答题并提交”按钮手动触发。

## 安装

1. 安装 Tampermonkey 浏览器扩展。
2. 新建用户脚本，将 `physics-lab-preexam.user.js` 的内容粘贴进去并保存。
3. 打开：

   ```text
   http://172.31.80.14:7101/Student/ReadyForExam/
   ```

4. 进入需要完成的实验预习，脚本会在试卷加载后自动答题并提交。

## 注意

- 每个实验预习通常最多可提交 3 次，脚本默认只自动提交一次。
- 如果只想自动填答案、不想自动提交，请删除脚本中的：

   ```js
   setTimeout(submitExam, 250);
   ```

- 本脚本仅供个人学习使用，请遵守学校相关规定。
