# 大物预习 · 一键答题

科大奥锐大学物理实验预习系统（`/Student/ReadyForExam/`）的自动答题工具。

> **在线使用 / 分享给别人：** https://c2451134117-cyber.github.io/physics-lab-preexam/

## 它是怎么工作的

这套预习系统的页面里有个 `view.NewContentXml()` 方法，会返回整份试卷的 XML，
每个 `<Question>` 节点都带着 `Type`（题型）和 `StdAnswer`（标准答案）。
脚本读这个 XML，然后按题型把答案写回页面控件，最后（可选）调用 `SubmitExam()` 交卷。

所以它不需要题库、不联网查答案，答案就是页面自己下发的。

## 三种用法

| 方式 | 适合 | 说明 |
| --- | --- | --- |
| 书签（Bookmarklet） | 偶尔用一次 | 打开 `index.html`，把按钮拖到书签栏 |
| 油猴脚本 | 长期用 | 装一次，之后打开试卷页自动答题 |
| 控制台 | 调试 | F12 粘代码回车 |

三种方式的按钮和代码都在 **`index.html`** 里，直接用浏览器打开即可。

## 支持的题型

| Type | 题型 | 处理方式 |
| --- | --- | --- |
| `SS` | 单选 | 点击 value 匹配的 radio |
| `MS` | 多选 | 按答案字母勾选 checkbox |
| `TF` | 判断 | 识别 正确/错误、对/错、√/×、T/F、1/0 |
| `BL` | 下拉填空 | 按 id 尾号排序后依次选值 |
| `SK` | 填空/简答 | 写入 textarea |

## 油猴脚本配置

打开脚本，改这一行：

```js
var AUTO_SUBMIT = true;   // 改成 false 就只填答案，不自动交卷
```

## 怎么看有没有成功

按 `F12` → `Console`，会看到：

```
[大物预习] 共 8 题，填充情况： {SS: 5, MS: 1, TF: 2, BL: 0, SK: 0}
```

如果出现 `这些题没填上：[...]`，说明页面结构和脚本的假设对不上，
把那行日志发出来，补一下选择器即可。
